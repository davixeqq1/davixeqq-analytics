      What do these metrics mean?
      Views
      How many times videos were viewed, as counted by YouTube.
      Watch time
      Total time viewers spent watching, shown in hours.
      Avg view duration
      Average length of one playback. Shorts are short by nature, so this number depends on how many Shorts were watched.
      Avg % viewed
      How much of a video an average playback covered. Long livestreams pull the channel-wide value down — compare each format separately.
      Shorts, long-form, livestream
      YouTube's own classification of each video (not guessed from length). Livestreams are never counted as long-form.
      Published
      Public uploads first published in the period (Pacific dates; livestreams by their actual start). Private, unlisted and scheduled uploads are not counted; uploads YouTube has not classified yet are shown as unclassified.
      Weakest video
      The video whose retention is furthest below the median of videos of the same format, among videos with enough views.
      Coverage
      How many of the period's views the per-video rows account for. Below 100 % the report says why (row limit of the API, views YouTube assigns to no video, or an unknown cause) and never rounds it up.
      Views by upload age
      Views from uploads published in the period compared with views of older videos — the same set of older videos in both weeks.
      API, derived, n/a
      API: returned directly by YouTube. Derived: calculated from per-video rows when YouTube did not return a total. n/a: not available — never shown as zero.
